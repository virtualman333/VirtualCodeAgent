# Python 重构技能

当用户要求重构 Python 代码时应用本技能。

## 检查清单

1. 先 `read_file` 完整读取目标文件，理解代码逻辑
2. 识别坏味道：
   - 重复代码 (DRY 违反)
   - 过长函数 (超过 40 行)
   - 深层嵌套 (超过 3 层缩进)
   - 魔法数字/字符串
   - 未使用的导入和变量
3. 重构策略：
   - 提取函数：将逻辑块提取为有意义的命名函数
   - 引入常量：替换魔法数字
   - 使用类型注解 `typing` / 内置泛型
   - 列表推导式替代简单 for 循环
4. 重构后：
   - 用 `bash` 运行 `python -m py_compile <file>` 检查语法
   - 如有测试，运行 `pytest` 验证行为不变

## 注意事项

- 保持行为完全一致，不做行为优化（除非用户要求）
- 不要过度设计，保持代码简单
- 保留原有注释风格
- 重构完成后总结变更点
